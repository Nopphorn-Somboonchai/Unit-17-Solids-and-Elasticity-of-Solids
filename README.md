## ✨ ฟีเจอร์หลักที่จะพัฒนา (Planned Key Features)

### 1. 📖 ระบบทบทวนบทเรียนแบบโต้ตอบ (Interactive Review & Simulators)
* **Simulator 1: การเปลี่ยนรูปของของแข็ง (Elastic vs Plastic Deformation Simulator)**
  * แอนิเมชัน 2D แสดงพฤติกรรมของวัสดุ (เช่น ลวดเหล็กกล้า, ยางรัด, ดินน้ำมัน) เมื่อถูกแรงดึงกระทำ
  * แสดงความยืดหยุ่นและการคืนรูปเดิมเมื่อแรงไม่เกินขีดจำกัดสภาพยืดหยุ่น (Elastic Limit)
  * แสดงสภาพพลาสติกที่เกิดการยืดถาวร ($\varepsilon_{\text{permanent}}$) เมื่อดึงเกินขีดจำกัด และแอนิเมชันการขาดออกจากกันที่จุดแตกหัก (Fracture Point)
* **Simulator 2: ห้องปฏิบัติการมอดุลัสของยังเสมือนจริง (Young's Modulus Virtual Lab)**
  * จำลองกิจกรรมการทดลองที่ 17.1 โดยนักเรียนสามารถเลือกลวดวัสดุต่าง ๆ (ทังสเตน, เหล็กกล้า, ทองแดง, อลูมิเนียม, แก้ว)
  * ผู้ใช้งานสามารถปรับความยาวสายดึง ($L_0$), เส้นผ่านศูนย์กลาง ($d$), และมวลที่ใช้ถ่วงน้ำหนัก ($m$) เพื่อคำนวณหาแรงดึง ($F = mg$)
  * ระบบจะพลอตกราฟความเค้น-ความเครียด ($\sigma - \varepsilon$) แบบเรียลไทม์ โดยนักเรียนจะเห็นความชันของกราฟที่สอดคล้องกับค่ามอดุลัสของยังของวัสดุนั้นๆ

### 2. 🧠 ระบบตะลุยโจทย์เฉพาะตัว (Roll-Number-Based Practice System)
* **ระบบสุ่มตัวแปรในโจทย์ (RNG)** - มีโหมดให้เลือกทั้งโจทย์มาตรฐาน (ตัวเลขตามคู่มือเรียน) และโจทย์สุ่มตัวแปร (Non-deterministic) เพื่อให้ผู้เรียนได้ฝึกการคำนวณตัวเลขที่ไม่ซ้ำกัน
* **หัวข้อคลังโจทย์คำนวณ**:
  * **โจทย์ความเค้นตามยาว**: คำนวณหา $\sigma = F/A$ พร้อมการแปลงหน่วยพื้นที่หน้าตัดเป็น $\text{m}^2$
  * **โจทย์ความเครียดตามยาว**: คำนวณหา $\varepsilon = \Delta L / L_0$ จากการเปลี่ยนความยาวของวัสดุ
  * **โจทย์คำนวณมอดุลัสของยัง**: คำนวณหา $Y = \frac{F L_0}{A \Delta L}$ จากมวลที่ถ่วงและระยะยืดที่เปลี่ยนแปลง
  * **โจทย์ขีดจำกัดความปลอดภัย**: หาแรงดึงสูงสุดหรือมวลสูงสุดที่จะไม่ทำให้ลวดโลหะสูญเสียสภาพยืดหยุ่นอย่างถาวร
  * **โจทย์วิเคราะห์อัตราส่วน**: เปรียบเทียบความเครียดหรือระยะยืดของวัสดุสองชนิดที่มีพารามิเตอร์ต่างกัน
* **ระบบเฉลยละเอียด**: แสดงผลการตรวจคำตอบทันที พร้อมแสดงวิธีทำอย่างเป็นขั้นเป็นตอนทีละสูตรในรูปแบบสมการ LaTeX ที่จัดวางสวยงามและเข้าใจง่าย

### 3. ⏱️ ระบบสอบเก็บคะแนน (Timed Exam System)
* **ระบบจำลองการสอบแบบจำกัดเวลา** - จำนวน 5 ข้อ (คะแนนเต็ม 10 คะแนน) โดยมีระยะเวลาจำกัดในการทำข้อสอบ **15 นาที** พร้อมตัวจับเวลาถอยหลัง (Timer) ในแถบเมนูด้านบน
* **การสอบแบบผสมผสาน** - ระบบจะสุ่มข้อสอบโดยมี **ข้อสอบแบบเลือกตอบ (Choice) เพียง 1 ข้อ** และ **ข้อสอบแบบคำนวณตัวเลข (Numeric Input) อีก 4 ข้อ** เพื่อวัดผลทั้งความเข้าใจเชิงทฤษฎีและทักษะการคำนวณอย่างรอบด้าน
* **ระบบป้องกันการโกง (Anti-cheat guard)** - แจ้งเตือนและป้องกันการรีเฟรชหน้าจอหรือออกจากหน้าสอบโดยไม่ตั้งใจ
* **Dashboard สรุปผล** - แสดงคะแนนรวม เวลาที่ใช้ พร้อมตารางสรุปสถานะการตอบแต่ละข้อ และปุ่มดูเฉลยละเอียดวิธีคิดอย่างเป็นขั้นเป็นตอน
* **ระบบบันทึกผลคะแนน** - บันทึกผลสอบล่าสุดเก็บไว้ใน Local Storage ของเบราว์เซอร์ เพื่อให้ผู้เรียนสามารถตรวจสอบคะแนนล่าสุดได้ที่หน้าแรก

## 🎯 กฎระบบข้อสอบแปรผัน (Dynamic Quiz System Rules)

ระบบข้อสอบในโปรเจกต์นี้ได้รับการออกแบบให้เป็น **Non-Deterministic Dynamic System** โดยผูกค่าตัวแปรในโจทย์เข้ากับ **"เลขที่ของนักเรียน (Roll Number: $R$)"** เพื่อให้มั่นใจว่านักเรียนแต่ละคนจะได้รับพารามิเตอร์โจทย์และคำตอบสุดท้ายที่ไม่ซ้ำกัน

### 📌 สถาปัตยกรรมและลอจิกการทำงาน:
1. **Dynamic Parameter Generation:** ระบบจะดึงเลขที่ของนักเรียน ($R$ ตั้งแต่ 1-40) มาคำนวณร่วมกับฐานตัวแปรที่ถูกสุ่มขึ้นมาแบบอิสระ (Non-deterministic Random) เช่น `T = T_base + R` หรือบวกเลขที่เข้าไปในพารามิเตอร์ เพื่อสร้างค่าพารามิเตอร์ชุดใหม่สำหรับโจทย์แต่ละข้อ
2. **On-the-fly Validation:** การประเมินคำตอบและเฉลยวิธีทำจะคำนวณแบบสดๆ (On-the-fly) จากเลขที่ $R$ ของผู้เข้าสอบจริง โดยไม่ใช้ค่าคงที่ตายตัว (No Static Hardcoded)
3. **Safety Constraints:** สมการเบื้องหลังได้รับการกำหนดขอบเขตค่าต่ำสุด-สูงสุดไว้อย่างรัดกุม เพื่อป้องกันไม่ให้การคำนวณร่วมกับเลขที่ $R$ เกิดค่าที่ติดลบหรือไม่สมเหตุสมผลทางฟิสิกส์

## 🛠️ เทคโนโลยีที่ใช้ (Tech Stack)

* **HTML5**: สำหรับจัดวางโครงสร้างและเนื้อหาเว็บแอปพลิเคชัน
* **Vanilla CSS (style.css)**: สำหรับการตกแต่งเพิ่มเติม เช่น แอนิเมชันกระบอกสูบ ปรับแต่ง Scrollbar และเอฟเฟกต์การตอบสนองของปุ่มต่างๆ
* **JavaScript (ES6+ / app.js)**: สำหรับควบคุมลอจิกทั้งหมด ระบบคำนวณฟิสิกส์ อัลกอริทึมการสุ่มและตรวจข้อสอบ ตลอดจนตัวจับเวลา
* **Tailwind CSS (via CDN)**: ใช้ในการจัดการ UI/UX, สีสัน, รูปแบบ Grid/Flex Layout และความ Responsive รองรับทั้งคอมพิวเตอร์ แท็บเล็ต และสมาร์ทโฟน
* **MathJax (via CDN)**: ไลบรารีสำหรับเรนเดอร์สมการคณิตศาสตร์และสูตรฟิสิกส์ด้วยฟอร์แมต LaTeX
* **FontAwesome**: บริการไอคอนที่ใช้แสดงสัญลักษณ์ในหน้าเว็บ
* **Google Fonts**: นำเข้าฟอนต์ 'Prompt' และ 'Sarabun' เพื่อให้อ่านง่าย สบายตา และดูมีความเป็นสากลและวิชาการ

## 🚀 วิธีการใช้งาน (How to Run)

1. ตรวจสอบให้มั่นใจว่าไฟล์ `index.html`, `app.js`, `style.css` และโฟลเดอร์โครงการทั้งหมดวางอยู่ในไดเรกทอรีเดียวกัน
2. ดับเบิลคลิกเปิดไฟล์ `index.html` ด้วยเว็บเบราว์เซอร์หลัก (เช่น Google Chrome, Microsoft Edge, Safari)
3. หากรันร่วมกับ Live Server บน VS Code จะช่วยหลีกเลี่ยงปัญหาเรื่องการเรียกใช้ไฟล์ข้าม Path ภายในเครื่องคอมพิวเตอร์
4. เครื่องคอมพิวเตอร์จำเป็นต้องเชื่อมต่ออินเทอร์เน็ตในการโหลดตัวอักษรและไลบรารีสคริปต์ต่างๆ จากผู้ให้บริการ CDN
